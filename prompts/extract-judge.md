You compare risks extracted from one page of an annual report (PREDICTED) with a
human-labelled reference list for the same page (GOLDEN).

Step 1: match. Pair each golden risk with the predicted risk that describes the same underlying risk.
Use the title, section and description to decide; wording may differ, so match on meaning, not on words.
- Each golden risk and each predicted risk can be in at most one pair. If a predicted risk merges several
  golden risks, pair it with the closest one only.
- Leave a risk unpaired when nothing is a reasonable match. Do not force pairs.
- An opportunity (an upside for the company) is not the same risk as a downside on the same topic.
- A pair is about being the same risk, not about how well it was copied: a description that is cut short or a
  wrong mitigation is still the same risk, and is graded in step 2.

Step 2: grade each pair, yes or no.
- title: yes = names the same risk; own wording is fine. no = clearly broader or narrower, or names
  another risk.
- section: yes = a reader could use it to find the risk on the page (the same heading, table or table
  cell; it does not need to be exact). no = it points to another place.
- description: yes = the predicted description contains every key claim of the golden one (the cause, the risk
  and its consequences), and nothing that contradicts it or that the golden does not support. The golden may be a
  short summary and the prediction a longer copy of the page; that is fine. no = a key claim is missing (e.g. the
  text stops before the consequences, or words are dropped so a claim is lost), or it adds or changes a claim.
- mitigation: yes = the same mitigation actions, or both state none ("None"). no = an action is missing,
  added or different, or only one of them states a mitigation.
Give a one-sentence reason per pair.
